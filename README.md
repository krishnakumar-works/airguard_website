#SMART AIR QUALITY DETECTION & ANALYSIS SYSTEM 

Developed an IoT system using ESP32 & air sensors to collect live environmental data , stored in firebase Realtime Database , displayed on a web dashboard with automated AQI-based warnings as per CPCB(central pollution control  board)  standards. 

USES:
IT can be used in hospital , collages , schools and various senstive places where quality of air must be the priority .
